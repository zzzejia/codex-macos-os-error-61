# Contributing

Useful contributions clarify a diagnosis, correct a command, or report a reproducible outcome. State your app version, macOS version, exact error, whether the local proxy port was listening, and whether the clean and normal launches completed a small task.

Distinguish confirmed observations from hypotheses. Do not claim that a particular VPN or tool installed a setting without evidence. A different error or cause deserves its own explanation rather than a broader universal-fix claim.

Never attach full environment dumps, shell startup files, process environments, app logs, session transcripts, screenshots containing private information, credentials, or account and device identifiers. Share only the minimum manually reviewed and redacted details needed to explain the result.

Do not add destructive reset instructions, automated configuration rewrites, installers, or commands that bypass network security policy. Keep changes narrowly scoped and reversible.
